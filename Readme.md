# Environment variables

| Название               | Значение по умолчанию | Описание                                                                          |
|------------------------|-----------------------|-----------------------------------------------------------------------------------|
| RESTORE_LIBRARY_CACHE  | true                  | Восстанавливать Library из артефактов из предыдущей удачной сборки                |
| SAVE_LIBRARY_CACHE     | true                  | Сохранять Library в артефакты для последующего переиспользования                  |
| CLEAR_WORKSPACE_BEFORE | false                 | Удалить из workspace перед сборкой все файлы и папки, которые игнорируются git'ом |
| WEBHOOK_URL            | ''                    | Вебхук для CI/CD                                                                  |
| WEBHOOK_ENABLED        | true                  | Отправляють вебхук для CI/CD                                                      |
| SETUP_PARAMETERS       | true                  | Установить параметры в настройках задачи                                          |
| SETUP_PARAMETERS_ONLY  | false                 | Отменить сборку после установки параметров                                        |
| NODE_LABEL             | unity                 | Метка ноды для сборки, если она не задана в `options.nodeLabel`                    |

# Build options

Задаются в `options` шаблона job'а и уезжают в `ci_build_options.json`, откуда их читает `JenkinsBuilder`.

| Название      | Значение по умолчанию | Описание                                                                                              |
|---------------|-----------------------|-------------------------------------------------------------------------------------------------------|
| version       | не задан              | Перебивает `PlayerSettings.bundleVersion`. Без него версия берётся из репозитория проекта              |
| buildNumber   | `env.BUILD_NUMBER`    | Уезжает в `Android.bundleVersionCode` и iOS `buildNumber`. В репозитории проекта номер сборки не хранится |
| hideUnityLogo | true                  | Выключает splash screen целиком, если лицензия это позволяет. Проекту со своим сплэшем нужен `false`   |
| nodeLabel     | `env.NODE_LABEL`      | Метка ноды. Лучше не задавать здесь: это свойство инфраструктуры, а не проекта                          |

## Android secrets

`options.android` принимает пароли либо напрямую, либо идентификаторами креденшелов Jenkins. Прямые значения продолжают работать как раньше; при указании обоих выигрывает креденшел.

| Поле                        | Тип креденшела | Во что превращается        |
|-----------------------------|----------------|----------------------------|
| keystoreCredentialsId       | Secret file    | `keystoreName` (путь)      |
| keystorePassCredentialsId   | Secret text    | `keystorePass`             |
| keyaliasPassCredentialsId   | Secret text    | `keyaliasPass`             |

`keyaliasName` секретом не является и задаётся значением.

Файл из Secret file существует только внутри блока `withCredentials`, поэтому Unity запускается внутри него же. По той же причине `ci_build_options.json` с уже подставленными паролями удаляется сразу после сборки — но только когда пароли пришли из креденшелов, чтобы не менять поведение старых job'ов.

# Tests

Юнит-тесты на библиотеку идут через JenkinsPipelineUnit, Jenkins и Unity для них не нужны:

```
gradlew test
```

Нужен JDK 21 или новее: `jenkins-pipeline-unit:1.31` собран под 21. Тесты компилируются Groovy 4, потому что компилятор Groovy 2.4 не читает байт-код 21.

Скрипты из `vars/` объявлены входом тестовой задачи. Без этого Gradle считает `test` UP-TO-DATE и после правки пайплайна молча пропускает прогон, показывая BUILD SUCCESSFUL без единого теста.
